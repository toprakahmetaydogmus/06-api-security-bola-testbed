## 🎯 1. Overview
An interactive FastAPI-based API security testing ground reproducing real-world Broken Object Level Authorization (BOLA), Broken Function Level Authorization (BFLA), Mass Assignment, and JWT signature bypass vulnerabilities with automated security unit tests.

---

## 🚀 2. Quick Start

```bash
git clone https://github.com/toprakahmetaydogmus/06-api-security-bola-testbed.git
cd 06-api-security-bola-testbed
python -m unittest discover tests/
```
